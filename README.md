### 📌 프로젝트 소개 (项目介绍)
- **취미 (爱好)**: 조깅 (慢跑 / Jogging)
- **실행 방법 (运行方式)**: 별도 설치나 서버 없이 `index.html` 더블클릭으로 모든 웹 브라우저에서 즉시 실행 가능합니다. (无需安装任何软件或服务器，双击 `index.html` 即可在浏览器中打开。)
- **언어 (语言)**: 한국어 / 中文 双语

### ✨ 주요 기능 (主要功能)
1. **취미 한 줄 소개와 제목 (标题与一句话介绍)**
   - 제목: 상쾌한 바람과 함께 달리는 조깅 (伴随清风奔跑的慢跑生活)
   - 한 줄 소개: *"바쁜 일상 속에서 몸과 마음을 건강하고 맑게 깨워주는 가장 쉽고 즐거운 달리기 운동입니다."* (“在繁忙的生活中唤醒身心健康、带来充沛活力与清爽心情的最轻松跑步运动。”)
2. **이모지 카드 3장 (3张Emoji卡片代替照片)**
   - 👟 가벼운 발걸음 (轻盈的步伐)
   - 🌅 자연과 아침 공기 (清晨空气与大自然)
   - 🎵 마음의 휴식과 해소 (心灵放松与解压)
3. **"이 취미를 시작하려면" 3단계 안내 (3个开始步骤)**
   - 1단계: 편안한 복장과 러닝화 준비 (准备装备)
   - 2단계: 스트레칭 후 가볍게 달리기 (热身并开跑)
   - 3단계: 주 2~3회 꾸준한 루틴 만들기 (坚持规律节奏)
4. **모바일 반응형 디자인 (移动端自适应设计)**
   - 스마트폰 화면에서도 글자가 잘리지 않도록 Flexbox/Grid 및 유연한 타이포그래피 적용
